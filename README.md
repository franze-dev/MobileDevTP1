# MobileDevTP1
Sofia Alvarez

A game coded in spanish made 15 years ago that I had to improve for my college in 2 months.
### Added:
- Single player
- Main Menu (and credits)
- Mobile compatibility (Basic tutorial and input)
- Design patterns
  - State
  - Service Locator
  - Observer
  - Command
- Loading screen
- Splash screen
- Loading of a prefab in runtime
- Easy and hard difficulty
- Scenes load async.
- Added canvas (When it was first made, Unity's Canvas did not exist)
